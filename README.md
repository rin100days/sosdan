# SOS단 정적 웹사이트

## 공유 모드(Supabase) 설정
이 버전은 **로컬 자동 폴백 없이** Supabase 공유 저장소를 기준으로 동작합니다.
즉, Supabase를 설정해야 다른 사람이 쓴 공지/입단/게시판/접속자수를 모두 함께 볼 수 있습니다.

### 1) Supabase 테이블 생성
SQL Editor에서 아래 실행:

```sql
create table if not exists sos_notices (
  id bigint generated by default as identity primary key,
  title text not null,
  content text not null,
  created_at timestamptz not null default now()
);

create table if not exists sos_joins (
  id bigint generated by default as identity primary key,
  name text not null,
  category text not null,
  message text not null,
  status text not null default 'pending',
  created_at timestamptz not null default now()
);

create table if not exists sos_bbs (
  id bigint generated by default as identity primary key,
  name text not null,
  message text not null,
  created_at timestamptz not null default now()
);

create table if not exists sos_metrics (
  id bigint generated by default as identity primary key,
  total_visits bigint not null default 0,
  created_at timestamptz not null default now()
);
```

### 2) RLS 정책 (데모용 공개)
```sql
alter table sos_notices enable row level security;
alter table sos_joins enable row level security;
alter table sos_bbs enable row level security;
alter table sos_metrics enable row level security;

create policy "public read notices" on sos_notices for select using (true);
create policy "public insert notices" on sos_notices for insert with check (true);

create policy "public read joins" on sos_joins for select using (true);
create policy "public insert joins" on sos_joins for insert with check (true);
create policy "public update joins" on sos_joins for update using (true) with check (true);

create policy "public read bbs" on sos_bbs for select using (true);
create policy "public insert bbs" on sos_bbs for insert with check (true);

create policy "public read metrics" on sos_metrics for select using (true);
create policy "public insert metrics" on sos_metrics for insert with check (true);
create policy "public update metrics" on sos_metrics for update using (true) with check (true);
```

### 3) `index.html` 설정
`index.html` 하단의 `window.SOSDAN_CONFIG` 값을 채우세요.

- `supabaseUrl`
- `supabaseAnonKey`

값이 비어 있으면 공유 기능은 비활성 상태로 표시됩니다.

### 4) 관리자 로그인
현재 데모 로그인 정보:
- ID: `admin`
- PW: `sos2006`

> 프론트 코드에 들어있는 데모 인증이라 보안용이 아닙니다. 실서비스는 서버 인증으로 교체하세요.

## 기능
- 공지사항: 관리자 로그인 시 작성 가능 (Supabase 공유)
- 입단 신청: 누구나 신청 가능, 관리자는 승인/보류 가능
- 자유게시판: 누구나 글 작성 가능
- 접속자수: Supabase 전역 집계
- 로고: 헤더/배너에 SOS단 로고 표시
